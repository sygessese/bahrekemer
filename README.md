# ባሕረ ቀመር · Bahrekemer

Bilingual (Amharic / English) static site for **bahrekemer.com**, hosted on GitHub Pages.

## Editing

| What | Where |
|---|---|
| Page text | `content/<page>.html` |
| Page titles, SEO descriptions, nav order, home-page cards | `site.json` |
| Header, footer, `<head>`/SEO template | `build.py` |
| Styles / toggle script | `assets/css/style.css`, `assets/js/main.js` |
| Images | `assets/img/` (author photo, `books/`, `paintings/`; `og.png` 1200×630 for link previews) |

Every piece of text is written twice, side by side:

```html
<span lang="am">አማርኛ</span><span lang="en">English</span>
<div lang="am"> …Amharic paragraphs… </div>
<div lang="en"> …English paragraphs… </div>
```

CSS shows only the active language. Add `class="always"` to keep an element visible in both
(used for the Amharic original beside English translations on Qene/Poetry).

Then rebuild (Python 3, no dependencies) and commit **both** `content/` and the generated pages:

```sh
python3 build.py
python3 -m http.server 8000   # preview at http://localhost:8000
```

Dashed gold boxes (`class="placeholder"`) mark text still to come.

## Language toggle & SEO

- Amharic is the default. The toggle remembers the choice (localStorage) and adds `?lang=en` to the URL,
  so English links are shareable.
- Each page has a canonical URL plus `hreflang` alternates (`/page/` = Amharic, `/page/?lang=en` = English).
- `sitemap.xml` and `robots.txt` are generated by `build.py`. Submit the sitemap in Google Search Console.

## Deploy (one-time)

1. **GitHub** → repo *Settings → Pages*: Source = *Deploy from a branch*, `main` / `(root)`.
   Custom domain = `bahrekemer.com` (the `CNAME` file already sets this). Tick **Enforce HTTPS** once the certificate is issued.
2. **GoDaddy** → *My Products → bahrekemer.com → DNS*:
   - Delete the existing `A @` record (GoDaddy "Parked") and turn off any domain forwarding.
   - Add 4 **A** records, name `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - Optional IPv6 — 4 **AAAA** records, name `@`: `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
   - **CNAME** `www` → `sygessese.github.io`
   - Leave any MX/TXT (email) records alone.
3. DNS can take up to an hour or so; GitHub's Pages settings page shows when the check passes.
